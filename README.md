# 自動筆記 — SYNC_AutoWriting

AviUtl2用のDelphiプラグインです。入力した文章を、ペンが文字を書くように少しずつ表示します。バージョン **v1.0.0**。

![本番AUF2による筆記サンプル](Sample/auto_writing.gif)

説明書用サンプルは白背景・黒文字です。本体の初期文字色は白です。

[設定プレビュー](Sample/settings_preview.png) / [書き順編集](Sample/stroke_editor.png) / [時間別の描画](Sample/timeline.png) / [転写方式の比較](Sample/transfer_comparison.png)

## 使い方

1. AviUtl2 2.1.16以降で、SYNCグループの「自動筆記」を追加します。
2. 「表示文字列」を入力するか、「設定」から複数行の文章を入力します。
3. AviUtl2側の「文字色」で色を指定します。初期値は白です。設定画面でも文字色を変更でき、両方の入力が同期します。フォント、文字サイズ、横書き・縦書き、字間・行間も設定画面で指定します。
4. 「筆記完了」の秒数を確認し、ペン速度を調整します。X座標・Y座標は画面中央からの移動量です。
5. 「ペンサイズ」で筆記具を拡大・縮小できます。100が標準、50が半分、200が2倍です。30〜300の範囲を0.01刻みで指定できます。「ペン角度」の初期値は右上向きの35°。0°は真上、正の値は右、負の値は左へ傾きます。範囲は−180°〜180°です。
6. 「光源X」「光源Y」で影の方向と伸び方を調整します。Xは左が−・右が＋、Yは上が−・下が＋。初期値はどちらも−100で、左上から照らします。
7. 設定画面を×で閉じると、文章・筆記具・ペンサイズ・角度・光源・詳細設定をAviUtl2の対象エフェクトへ反映します。「適用」「キャンセル」のボタンはありません。

AviUtl2側の「表示文字列」と設定画面の入力欄は、どちらも複数行を入力できるメモ形式です。Enterで改行できます。バックスラッシュや `\n` は入力した文字のまま表示します。

筆記時間は経路と画間・文字間・改行時のペン移動距離、およびペン速度から計算します。オブジェクトの長さや拡大率では変化しません。最後まで書くと完成形を保持します。途中で終わるオブジェクトは、その時点の状態を表示します。再生位置を戻しても同じ時刻は同じ描画になります。

## 設定画面

設定画面の操作部はダーク配色です。Windowsの表示倍率（200%表示を含む）に合わせて拡大します。文章プレビューと1文字再生の背景は、文字色に対してコントラストが大きくなる白か黒を自動選択します。黒文字なら白背景、白文字なら黒背景です。

フォントは上部のコンボボックスから選択し、横のチェックで太字・斜体を指定します。基準サイズとペンサイズ、字間と行間、角度と持上げ高さ、光源X/Yを横並びにし、文字種別の倍率も2列にまとめています。設定欄が縦に収まらない場合はホイールでスクロールでき、数値入力欄にフォーカスがあっても値を変えません。文章欄と開いた選択リストはそれぞれのスクロールを優先します。

「プレビュー」は独自の背景で自動再生・ループします。画面に収まるよう表示だけ縮小します。Spaceで一時停止・再開、「先頭から再生」でやり直せます。文字入力欄や数値入力欄にフォーカスがある場合は、Spaceを文字入力に使用します。

漢字・ひらがな・カタカナ・数字・英字・記号のサイズ比率を個別に設定できます。ペン種類は「鉛筆・ボールペン・万年筆・毛筆・羽ペン・無し」の順に並びます。筆記具と影を非表示にする場合は、末尾の「無し」を選びます。旧版で「ペン・筆を表示」をOFFにした設定は、設定画面を開くと「無し」として引き継ぎます。

筆記具の表示サイズ・角度・持ち上げる高さを調整できます。羽ペンは羽軸・羽毛・羽の筋を自動描画し、角度・サイズ・持上げ・光源にも対応します。画像の用意は不要です。[羽ペンの描画例](Sample/quill.png)

AviUtl2側の「ペン」グループは、種類 → 速度 → サイズ → 角度 → 光源X → 光源Yの順です。「設定」ボタンはグループの外、一番下にあります。

ペンサイズ・ペン角度・光源X/YはAviUtl2側のパラメーターと共通です。ペンサイズは文字の大きさと独立し、ペン先を基準に筆記具と影を調整します。紙に接しているペン先では影が重なり、軸の後端ほど高さがあるため影が離れて柔らかくなります。ペンを持ち上げるとペン先の影も離れます。持上げ高さ0でも軸の影は残り、筆記具を非表示にすると影も消えます。[接地中と持上げ中の影](Sample/pen_lift.png)

光源はペン先を基準にした方向で指定します。左から照らすと右へ、上から照らすと下へ影が伸びます。範囲はそれぞれ−400〜400です。ペンサイズ・角度・光源・持上げ高さを変えても筆記時間は変わりません。

「書き順編集」は、左に重複を統合した文字一覧、中央に色分けした経路と画番号、右に各画の一覧を表示します。

- 選択した画は白黒の縁が付いた太い色線で最前面に表示し、ほかの画は淡く表示します。塗り丸が始点、四角が終点で、経路上の矢印が進む方向です。始点・終点には画番号とラベルも表示します。
- 直線の操作点は基本的に両端だけにし、折れや曲線には形を示す操作点を残します。描画用の細かな経路は維持するので、操作点を減らすだけでは筆記の形や時間は変わりません。
- 中央で操作点をクリックすると、画の色を使った大きな丸と画番号で選択位置を表示します。重なる点・線は色付き候補から選びます。右クリックの「重なる点・線を選び直す」でも切り替えられます。
- **頂点作成**：操作点のない線を直接右クリック→「頂点を作成」（Ctrl+I）。その位置へドラッグ可能な操作点を追加し、次回も表示します。
- 頂点を選択したあと、その丸をドラッグすると位置を移動できます。重なっていても選択中の頂点を優先し、隣の頂点までの経路がつながったまま変形します。選択だけでは学習を保存しません。
- **頂点の削除**：中央で頂点を選択し、右クリック→「この頂点を削除」。隣の頂点どうしをつなぎ直します。2頂点だけの画を消す場合は、右の一覧から画ごと削除します。
- **画の削除**：右の一覧で不要な画を選び、右クリック→「選択した画を削除」。点だけ残った画や、Ctrl／Shiftで選択した複数の画も削除できます。
- **分割**：切りたい線を直接右クリック→「ここで分割」（Ctrl+K）。先に頂点を作る必要はありません。既存の操作点で分割することもできます。
- **方向の反転**：中央で点を選び、右クリック→「この画の描画方向を反転」。選択位置を保ったまま、その画の始点と終点を入れ替えます。右の一覧からも選択した画を反転できます。
- **画の順序**：右の一覧で画をドラッグします。挿入先を青い横線で表示します。Ctrl／Shiftで複数選択した画も、元の順序のまままとめて移動できます。
- **結合**：右の一覧でCtrl／Shiftを使って複数の画を選び、右クリック→「選択した画を結合」（Ctrl+J）。主線の途中につながる短い枝は自動吸収します。長い画や大きく曲がった画は経路を残し、近い端点を使うよう方向をそろえて一覧順に結びます。
- 反転・上下移動・元に戻す・やり直す・自動推定へのリセットも右クリックメニューから操作します。右側の操作ボタン群はありません。
- 元に戻す／やり直すは同じ文字の50操作まで保持します。別の文字やフォントを選ぶと履歴をリセットします。保存した学習の状態も戻します。
- Spaceで選択した1文字の筆記を繰り返し再生します。もう一度押すと経路表示に戻ります。
- 「自動推定に戻す」で選択した文字の学習を削除します。

筆順・方向・経路の変更は操作時に即時保存します。文章と詳細設定は設定画面を閉じると反映します。

例えば「自」の上の短い画が上辺・右の縦画につながっている場合は、切りたい接続位置を右クリックし、対象の画の色を確認して「ここで分割」を選びます。別の画の端点と重なる場合も、候補から対象の線を選べます。

「に」の左側など、途中から短い枝が出ている場合は、主線と枝を選んで通常どおり結合してください。枝先への往復や画間移動を作らず、主線の前後をつなぎ直します。結果はCtrl+Zで戻せます。[枝の自動吸収の例](Sample/branch_absorption.png)

| 操作 | ショートカット |
| --- | --- |
| 線上に頂点を作成 | Ctrl+I |
| 選択点で分割 | Ctrl+K |
| 選択した画を結合 | Ctrl+J |
| 向きを反転 | Ctrl+R |
| 選択した頂点／一覧の画を削除 | Delete |
| 上へ／下へ移動 | Alt+↑／Alt+↓ |

ショートカットは書き順編集画面で使用します。文字・数値入力中は入力欄の操作を優先します。

## 学習データ

保存先はWindowsのマイドキュメント内の **SYNC_AutoWriting** フォルダーです。マイドキュメントを別ドライブやOneDriveへ移動している場合も、その既知フォルダーに従います。

`Fonts/<フォント識別ハッシュ>/<文字のUTF-16コード>.json` に、画の並び・方向・補正経路・追加した操作点を保存します。同じフォントの同じ文字に共通で適用し、再起動後も読み込みます。フォントを変えると別の学習を使用します。バックアップはこのフォルダーをコピーしてください。

フォントファイル、元の文字輪郭、描画マスクは保存しません。フォントは同梱せず、インストール済みのアウトライン対応フォントを参照します。フォントの利用条件を確認してください。

## 現在の範囲

フォント形状の細線化と接続方向から筆順を推定します。ユーザーが修正したフォント別学習を最優先し、学習がない場合は、ひらがな・カタカナ176文字と英大文字・小文字・数字62文字の書き順参照データで推定を補助します。参照の位置・方向・曲がり方を選択フォントの実際の中心線へ照合し、字形との一致や改善が明確な場合だけ採用します。形状・接続が合わない文字と参照がない文字は従来推定を使います。完成時は元フォントのマスクに一致します。

参照データはフォント非依存でAUF2へ組み込まれており、通信やPython等は不要です。ユーザー学習のファイルへ自動登録しません。参照は手書きの形を基準とするため、つながった「き」や二階建てのa/g、明朝の飾りなどは従来推定へ戻る場合があります。漢字・筆記体への参照拡張は今後の対象です。必要な修正は従来どおり書き順編集で行えます。

フォント中心線への位置合わせを行い、画の再構成が合わない書体でも、対応が明確なら元の点列を保って順序・方向だけを参照から補正します。文字一覧の「参照」、中央の「書き順参照」または「書き順参照（順序・方向）」で採用を確認できます。ユーザーが修正した文字は「学習済み」を優先します。

筆記途中は、元フォントから各画に対応する領域を求め、その領域を経路に沿って転写するように表示します。交差部分は周囲の線幅を保って共有し、後続画による欠けや、未筆記画が点状に先に見える現象を抑えます。領域は字形と経路からの近似のため、複雑な交差や装飾部分の表示時期には調整の余地があります。

毛筆は筆記具の表示に対応し、筆圧・毛先の変形は今後の改良対象です。縦書きは右から左への列送りと句読点位置の基本対応です。縦組み専用字形・禁則処理・結合文字の組版・補助平面文字は未対応です。未収録文字は□で表示し、設定画面に案内します。最大4096 UTF-16文字です。
