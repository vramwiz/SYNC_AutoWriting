# 実装状況 — v1.0.0

| 分野 | 現在の動作 |

| 配置 | 入力改行、横書き、右から左へ列を送る縦書き、比率指定の字間・行間、6文字種のサイズ、共通ベースライン |
| プレビュー | 本体と同一の描画器、独自背景、初期自動再生・ループ、Space停止/再開、完了秒数、変更の300ms遅延反映。不透明な独立ウィンドウをダブルバッファで更新し、背景消去によるちらつきを防止 |
| 筆順編集 | 3ペイン。選択画は白黒の縁と8px色線、ほかは淡色。繰り返す方向矢印、丸い始点・四角い終点と番号ラベル。画一覧のCtrl/Shift複数選択、複数行ドラッグと挿入先の横線 |

| 編集履歴 | 同一文字で50操作の元に戻す/やり直す。順序・反転・ドラッグ・分割・結合・自動推定へのリセットに対応し、学習の保存状態も復元 |
| 学習 | フォント×文字のJSON、太字/斜体とフォント情報のハッシュ、順序・方向・補正経路の即時保存、再起動後再利用、原子的置換 |
| キャッシュ | 文字形状・経路を文字ごとに保持、組版が同じなら再生成しない。UIの学習変更で本体を無効化。毎フレームの再解析なし |
| 筆記具 | 鉛筆・ボールペン・万年筆・毛筆をコード描画。ペン先追従、画間移動時の持ち上げ、表示OFF・サイズ・傾き・持上げ高さ |
| 画像合成 | 入力RGBAへsource-over合成。入力なしの場合はシーン寸法の透明背景。有限寸法・画素数を検証 |

## 初期版の制限と次の改良

- 自動推定は日本語筆順辞書や学習モデルによる認識ではない。交差、閉じた輪、明朝のセリフ、手書き風の接続は誤分割や順序違いが残る。順序・反転・点補正・分割・結合で調整できる。空白から画を新規作成する操作はまだない。
- 画別領域は経路、法線断面、近傍幅と字形内の領域成長から近似する。フォントに画別輪郭は含まれないため、複雑な接続や装飾では露出時期が不自然になる場合がある。経路が通らなかった成分は最後に表示する。厳密な筆圧モデルは未実装で、はね・はらいの自然さは実例で継続調整する。
- 毛筆は筆記具の描画と移動に対応。文字形状を変える筆圧、毛先の物理変形、とめの滞留時間は未実装。
- 文字形状は128 emのアンチエイリアスマスクを使用する。極端な拡大時はマスク解像度の改善が必要。
- 縦書きは基本配置と句読点位置。OpenTypeの縦組み字形、回転括弧・長音、禁則、欧文の高度なシェーピングは未実装。
- Unicodeはサロゲート対を分割せず扱うが、現在のGDI字形取得はBMPが対象。補助平面文字・結合文字・字形連結は今後対応。未収録文字は□で通知する。
- フォントを後から置換したときはhead/name等の識別が変わるため、既存学習を自動移植しない。外部で学習ファイルを直接編集した場合はプラグインを読み込み直す。
- マイドキュメントへ保存できない環境では学習保存時にエラーを表示する。書き出せないデータを保存済みと扱わない。
- CPU描画。実機のAviUtl2とIDEの操作・FPSは今回の自動検査範囲外。

## 検査

`Tests/run_tests.ps1` は実際の本番AUF2をLoadLibraryし、4エクスポート、登録名・グループ・フラグ・項目、バージョン拒否、フレーム描画を検査する。

完成字形は、独立にGDIで取得した「永」のマスクと画素単位で比較する。12段階のインク非減少、逆シーク、完了後保持、速度と時刻の等価、拡大率と完了時間の独立、4種筆記具、透明度、XY移動、縦書き、文字種、入力合成、空入力と無効ポインターを検査する。

学習保存・再読込・順序/反転/座標・破損ファイル保持は一意の検査用フォントIDで確認する。本番DLLの設定ボタンも専用検査フォームとして開き、改行文章と筆記具を変更して対象エフェクトへの保存を確認する。プレビュー・3ペイン編集のPNGを保存して目視確認する。IDEとAviUtl2は起動しない。

最新ビルドログ・描画画像・照合結果は `Win64/LatestVerification`。最終ビルド・配置情報は同フォルダーの `ReleaseArtifact.json`。

2026-11-18の最終確認ではDebug / Releaseとも警告0・エラー0で、本番AUF2の全検査が成功した。描画画像11枚が両構成で一致し、コピーしたsetup5ファイル・共通ファイル4件も参照元と一致した。`Sample/auto_writing.gif` はRelease本体から出力した149フレーム（20fps、筆記6秒）による確認用アニメーション。

v0.1.1で設定画面のちらつきを修正した。文章と1文字再生の両描画面で、WM_ERASEBKGNDから次の描画まで表示済みフレームを保持することを検査した。RGBA配列と表示用DIBも再利用する。動画用の描画画像11枚はv0.1.0と一致している。修正のビルド・検査・画像照合記録は `Win64/FlickerFix`。

v0.1.2で、点を正確に選ぶ必要があった分割を「線上をクリックする分割モード」へ変更し、次の行だけに限られていた結合を「端点を指定する任意2画の結合モード」へ変更した。Undo/Redoを追加し、クリックだけで点を動かしたり学習を保存したりしないようドラッグのしきい値も設けた。実字形「自」の1画目の分離、4通りの端点方向、離れた行の結合、履歴の独立性と学習再読込を検査する。本番の専用UIでも分割・Undo・Redo・端点結合・Undoによる保存削除まで検査する。UI検査には未使用の私用文字を選び、既存の文字の学習ファイルには書き込まない。記録は `Win64/StrokeEditing`。

v0.1.3で編集操作を右クリックメニューへ再構成した。点の選択を大きい色付き丸で示し、重なりは画・点番号付き候補から選択する。分割は選択点の右クリック、結合は画一覧の複数選択から実行する。複数行ドラッグは挿入スロット0..Countへ移動し、横線を表示する。設定画面を閉じると反映する。検査は実際のポップアップからコマンドを選び、候補選択・分割・複数選択結合・ショートカット・ドラッグ中の横線の画素・移動後の順序とUndoを確認する。既存データへ書き込まない検査を維持し、記録は `Win64/EditorMenus`。

v0.1.4で選択画を太線と縁取りで最前面に強調し、方向矢印と始点・終点ラベルを追加した。点の右クリックにも方向反転を明示し、反転後も選んだ物理的位置を保持する。専用UIで太線の表示画素、実際のメニューからの反転、保存された始終点とUndoを検査する。

同版で、各画素を一つの経路へ排他的に割り当てていた露出処理を `AutoWriting_Reveal.pas` に分離し、筆跡の重ね合わせへ変更した。十字の合成字形で先行画が交差部で欠けないこと、後続画の遠方が先に出ないこと、元マスク・経路距離の不変を検査する。実字形「自」も旧版・新版の本番AUF2で同じ時刻に描画して比較する。`Tests/run_tests.ps1 -GlyphSamplesOnly` で各画の終わりをPNGに出力できる。完成形は独立GDIマスクと引き続き画素一致する。ビルド・検査・比較画像は `Win64/SelectionDirection`。

v0.1.5で、円形の筆跡が太い未筆記画を点状に拾う問題へ対応した。全経路を同時に種として画別領域を確保し、交差部分は接線に垂直な細い帯で転写する。近傍の通常幅から交差部の幅の膨張を制限し、帯で転写できた領域を元の領域成長より優先する。等幅十字、細い横画と太い縦画、縦横を入れ替えたケースで、先行画の欠けがなく、後続画の交差領域外が先に出ないことを検査する。実際の学習済み「自動」も旧版と同時刻に本番AUF2から出力して比較する。比較用は黒文字・白背景へ固定し、初期文字色の変更と混同しない。完成画像と各画の終了時刻は旧版と一致する。記録は `Win64/StrokeTransfer`、比較画像は `Sample/transfer_comparison.png`。

帯の外側のアンチエイリアス縁や飾りも、中心線ではなく転写領域の端から補う。同距離で所属が曖昧な縁は後の画へ割り当て、細い先行画が太い未筆記画の外縁を先に拾う現象を抑える。

同版で新規追加時の初期文字色を白へ変更した。既存の詳細JSONの文字色は優先して読み込み、保存済み設定を書き換えない。

v1.0.0の公開準備では本体の表示番号とWindowsファイル情報、AutoWriting専用カタログをそろえた。配布バッチはRelease本体の製品名・バージョンを照合し、ZIPへ入れるAUF2のXXH3-128をJSONへ設定する。内部番号の公開履歴は含めない。配布手順は `setup/README.md`。
