## 初期版の制限と次の改良

- 自動推定は日本語筆順辞書や学習モデルによる認識ではない。交差、閉じた輪、明朝のセリフ、手書き風の接続は誤分割や順序違いが残る。順序・反転・点補正・分割・結合で調整できる。空白から画を新規作成する操作はまだない。
- 画別領域は経路、法線断面、近傍幅と字形内の領域成長から近似する。フォントに画別輪郭は含まれないため、複雑な接続や装飾では露出時期が不自然になる場合がある。経路が通らなかった成分は最後に表示する。厳密な筆圧モデルは未実装で、はね・はらいの自然さは実例で継続調整する。
- 毛筆は筆記具の描画と移動に対応。文字形状を変える筆圧、毛先の物理変形、とめの滞留時間は未実装。
- 文字形状は128 emのアンチエイリアスマスクを使用する。極端な拡大時はマスク解像度の改善が必要。
- 縦書きは基本配置と句読点位置。OpenTypeの縦組み字形、回転括弧・長音、禁則、欧文の高度なシェーピングは未実装。
- Unicodeはサロゲート対を分割せず扱うが、現在のGDI字形取得はBMPが対象。補助平面文字・結合文字・字形連結は今後対応。未収録文字は□で通知する。
- フォントを後から置換したときはhead/name等の識別が変わるため、既存学習を自動移植しない。外部で学習ファイルを直接編集した場合はプラグインを読み込み直す。
- マイドキュメントへ保存できない環境では学習保存時にエラーを表示する。書き出せないデータを保存済みと扱わない。
- CPU描画。実機のAviUtl2とIDEの操作・FPSは今回の自動検査範囲外。

## 検査

`Tests/run_tests.ps1` は実際の本番AUF2をLoadLibraryし、4エクスポート、登録名・グループ・フラグ・項目、バージョン拒否、フレーム描画を検査する。

完成字形は、独立にGDIで取得した「永」のマスクと画素単位で比較する。12段階のインク非減少、逆シーク、完了後保持、速度と時刻の等価、拡大率と完了時間の独立、4種筆記具、透明度、XY移動、縦書き、文字種、入力合成、空入力と無効ポインターを検査する。

学習保存・再読込・順序/反転/座標・破損ファイル保持は一意の検査用フォントIDで確認する。本番DLLの設定ボタンも専用検査フォームとして開き、改行文章と筆記具を変更して対象エフェクトへの保存を確認する。プレビュー・3ペイン編集のPNGを保存して目視確認する。IDEとAviUtl2は起動しない。

最新ビルドログ・描画画像・照合結果は `Win64/LatestVerification`。最終ビルド・配置情報は同フォルダーの `ReleaseArtifact.json`。

帯の外側のアンチエイリアス縁や飾りも、中心線ではなく転写領域の端から補う。同距離で所属が曖昧な縁は後の画へ割り当て、細い先行画が太い未筆記画の外縁を先に拾う現象を抑える。

v1.0.0の公開準備では本体の表示番号とWindowsファイル情報、AutoWriting専用カタログをそろえた。配布バッチはRelease本体の製品名・バージョンを照合し、ZIPへ入れるAUF2のXXH3-128をJSONへ設定する。内部番号の公開履歴は含めない。配布手順は `setup/README.md`。

同準備中に操作点を整理した。描画用の細かな点列は維持し、解析用128px基準で0.75px以内の誤差で導出した操作点とユーザーが追加した固定点を表示する。線上の右クリックで頂点作成（Ctrl+I）・直接分割（Ctrl+K）ができ、別画の端点に重なる線や自己交差の別区間も候補に残す。操作点のドラッグは隣の操作点まで距離に比例して点列を変形し、1点だけ動く突起を避ける。

固定点は学習JSONの画ごとの任意項目`vertices`へ点列の添字として保存する。schemaは1のまま旧データも読み込める。反転・分割・結合時に添字を変換し、履歴は点列・固定点を独立して複製する。記録は `Win64/SparseVertices`。

通常の結合操作で枝を自動判定する。一端が主線内部の1.5px以内にあり、反対側の端と途中が主線から離れる経路を対象にする。端点接続・両端接続の輪・並行する重複経路は枝扱いしない。選択全体で枝を先に処理し、主線の前後を三次の重みで変形して枝先を通す。主線のID・方向・始終点と周辺の手動固定点、未選択画は保持する。結合後も通常の保存・Undo/Redoを利用する。

枝の両方向・主線の両方向・一覧順の違い・複数枝・通常結合・保存再読込を検査する。実際の「に」の学習は読取専用で複製して比較画像を作成し、本番DLLの専用UIでも既存の結合メニュー→保存→Undo→Redoを検査する。記録は `Win64/BranchAbsorption`。

初回公開準備中に、筆記具の初期傾斜を左右反転した。角度は0°で真上、正で右、負で左へ傾く。−180°〜180°、ホスト側は0.1°単位。既存項目の登録順を保ってペン角度を末尾へ追加し、この値を旧詳細JSONの角度より優先する。設定画面で角度を変えない場合は、ホストの小数値・中間点表記と旧詳細JSONを保持する。角度を配置キャッシュのキーから除き、角度のアニメーションで再解析しない。

影は筆記具の各断面の高さから平行投影する。接地中のペン先の影は同じ位置へ重なり、軸の後端に向かうほど高さ・影の距離・ぼかしが増える。画間移動では持上げ高さ×正弦波を全断面へ加え、ペン先の影も離す。高さ0でも後端の影を保ち、筆記具非表示時は影も描かない。拡大率・透明度に追従し、同じ時刻は同じ影になる。

右/左への傾斜、旧詳細JSONに対するホスト角度の優先、角度変更時の配置配列の再利用、影の出現・非表示・透明度・逆シーク、文字形状と筆記時間の不変を本番AUF2で検査した。専用設定フォームで角度の変更反映と無変更の中間点保持も検査。Debug / Releaseは警告0・エラー0、各1,022,381項目成功。記録は `Win64/PenLift`。説明書GIFも新しい向きと影を使い、白背景・黒文字で再生成した。公開番号・設定/学習スキーマは変更していない。

その後、影をペン全体の一律オフセットから上記の高さ別投影へ修正し、光源X/Y（各−400〜400、初期値−100）を追加した。ペン先基準・仮想高さ200固定の方向光として扱い、軸の高さは表示長の0.55倍とする。光源のX正は右、Y正は下で、影は光源の反対へ伸びる。表示用のペンの傾きは維持する。光源を組版キーから除外し、学習や筆記時間へ影響させない。光源と軸の向きが重なって影がほぼ点になる場合も処理する。

本番AUF2で接地したペン先付近の影の弱さ・後端の影、光源XYの両方向、ホスト値の優先、配置再利用、持上げ高さ0の軸の影、専用設定画面との同期と中間点保持を検査した。Debug / Releaseとも警告0・エラー0、各1,022,422項目成功。描画21画像が両構成で一致し、筆記具を含まない7画像は変更前と一致した。記録は `Win64/ShadowProjection`。設定JSONは任意の`lightX`/`lightY`を追加し、schemaは1を維持する。旧設定は初期の左上光源を使用する。

ペンサイズをAviUtl2側へ追加し、100＝従来の標準、30〜300を0.01刻みとした。設定画面は小数2桁・上下キー0.01刻みのTNumberBoxで同期する。内部の倍率と詳細JSONの`penSize`は従来どおり1＝100とし、schemaは変更しない。無変更のサイズの中間点・小数値を保持し、表示で丸められても保存時に上書きしない。サイズを組版キーから除外し、文字や筆記時間を保ったまま筆記具と影を拡縮する。検査記録は `Win64/PenSize`。

ペン種類に「無し」と「羽ペン」を追加した。既存の識別値（鉛筆0・ボールペン1・万年筆2・毛筆3）と初期値の万年筆2を保ち、無し4・羽ペン5を追加する。表示は配列順と識別値順をそろえ、「無し」を末尾へ配置する。ホストの無しの識別値は6で、旧4は読取互換として受け付ける。設定画面のリスト添字と保存識別値を分け、開閉時に既存種類が変わらないようにする。「無し」は表示チェックONでも筆記具・影を描かず、描画距離と筆記時間は同じ。

Debug / Releaseとも警告0・エラー0、各1,022,699項目成功。種類の表示順・既存ID、無しの筆記具/影の非表示、羽ペンの本番描画・逆シーク・表示OFF・透明度・角度/サイズを確認。専用設定画面から無し・羽ペンを選択してホストへ反映することと、従来の万年筆を開閉時に保つことも検査した。描画26画像が両構成で一致し、既存23画像は変更前とも一致した。

羽ペンの負荷をAW_PROFILE付きDebug/Releaseで計測し、羽毛本体の画素ごとのSin/Powerと広い走査範囲を主因と確認した。輪郭・羽軸を1/8px刻みの不変の表に保持し、描画範囲を回転した羽の行ごとに絞り、輪郭外では羽の筋の計算を省く。影も共通の表を使う。通常ビルドには計測用エクスポート・タイマーを含めない。CLIで本番AUF2を1920×1080・入力なし・各48フレーム（ウォームアップ除外）で比較した結果、通常Releaseの羽ペン100%は約12.0→1.3ms、300%は約99.4→8.9ms、約9倍/11倍に高速化した。AviUtl2実機のFPSではない。

「無し」は両UIで末尾に統一した。既存4種の識別値0〜3と羽ペン5を保ち、無しは6とし、旧4を読取互換で扱う。配列順だけでなく識別値順も同じなので、ホスト側が番号順で表示しても端になる。Debug/Releaseは警告0・エラー0、各1,022,709項目成功。描画26画像が両構成および変更前で一致し、9角度×3サイズの27条件でも全走査参照と最適化した走査が全画素一致した。検査・比較はWin64/QuillOptimization、計測はTests/run_benchmark.ps1。本体の運筆・字形・時間・公開番号は維持する。
