## 2026-11-19 文字間のペン移動速度

- 「ペンの移動速度」をAviUtl2のペングループと設定画面に追加。文字間と改行先への移動に適用し、0はペン速度に連動する。設定画面の完了時刻とフレーム描画は共通の組版情報から計算する。

## 2026-11-19 英大文字の筆順とセリフ

- A・E・F・H・K・L・M・N・P・R・T・V・W・X・Y で印刷体の主画を照合する。M・N・T・W に字体候補を追加した。V・W は実際の下端を通り、E・F・L・N などの短い飾りは主画に属するインクとして表示する。

## 2026-11-19 英小文字の筆順とセリフ

## 初期版の制限と次の改良

- 自動推定は汎用の文字認識や学習モデルではない。かな・英数字は参照で補助するが、漢字の参照は未収録。交差、閉じた輪、明朝のセリフ、手書き風の接続は誤分割や順序違いが残る。順序・反転・点補正・分割・結合で調整できる。空白から画を新規作成する操作はまだない。
- 画別領域は経路、法線断面、近傍幅と字形内の領域成長から近似する。フォントに画別輪郭は含まれないため、複雑な接続や装飾では露出時期が不自然になる場合がある。経路が通らなかった成分は最後に表示する。厳密な筆圧モデルは未実装で、はね・はらいの自然さは実例で継続調整する。
- 毛筆は筆記具の描画と移動に対応。文字形状を変える筆圧、毛先の物理変形、とめの滞留時間は未実装。
- 文字形状は128 emのアンチエイリアスマスクを使用する。極端な拡大時はマスク解像度の改善が必要。
- 縦書きは基本配置と句読点位置。OpenTypeの縦組み字形、回転括弧・長音、禁則、欧文の高度なシェーピングは未実装。
- Unicodeはサロゲート対を分割せず扱うが、現在のGDI字形取得はBMPが対象。補助平面文字・結合文字・字形連結は今後対応。未収録文字は□で通知する。
- フォントを後から置換したときはhead/name等の識別が変わるため、既存学習を自動移植しない。外部で学習ファイルを直接編集した場合はプラグインを読み込み直す。
- マイドキュメントへ保存できない環境では学習保存時にエラーを表示する。書き出せないデータを保存済みと扱わない。
- CPU描画。実機のAviUtl2とIDEの操作・FPSは今回の自動検査範囲外。

同準備中に操作点を整理した。描画用の細かな点列は維持し、解析用128px基準で0.75px以内の誤差で導出した操作点とユーザーが追加した固定点を表示する。線上の右クリックで頂点作成（Ctrl+I）・直接分割（Ctrl+K）ができ、別画の端点に重なる線や自己交差の別区間も候補に残す。操作点のドラッグは隣の操作点まで距離に比例して点列を変形し、1点だけ動く突起を避ける。

固定点は学習JSONの画ごとの任意項目`vertices`へ点列の添字として保存する。schemaは1のまま旧データも読み込める。反転・分割・結合時に添字を変換し、履歴は点列・固定点を独立して複製する。記録は `Win64/SparseVertices`。

通常の結合操作で枝を自動判定する。一端が主線内部の1.5px以内にあり、反対側の端と途中が主線から離れる経路を対象にする。端点接続・両端接続の輪・並行する重複経路は枝扱いしない。選択全体で枝を先に処理し、主線の前後を三次の重みで変形して枝先を通す。主線のID・方向・始終点と周辺の手動固定点、未選択画は保持する。結合後も通常の保存・Undo/Redoを利用する。

枝の両方向・主線の両方向・一覧順の違い・複数枝・通常結合・保存再読込を検査する。実際の「に」の学習は読取専用で複製して比較画像を作成し、本番DLLの専用UIでも既存の結合メニュー→保存→Undo→Redoを検査する。記録は `Win64/BranchAbsorption`。

初回公開準備中に、筆記具の初期傾斜を左右反転した。角度は0°で真上、正で右、負で左へ傾く。−180°〜180°、ホスト側は0.1°単位。既存項目の登録順を保ってペン角度を末尾へ追加し、この値を旧詳細JSONの角度より優先する。設定画面で角度を変えない場合は、ホストの小数値・中間点表記と旧詳細JSONを保持する。角度を配置キャッシュのキーから除き、角度のアニメーションで再解析しない。

影は筆記具の各断面の高さから平行投影する。接地中のペン先の影は同じ位置へ重なり、軸の後端に向かうほど高さ・影の距離・ぼかしが増える。画間移動では持上げ高さ×正弦波を全断面へ加え、ペン先の影も離す。高さ0でも後端の影を保ち、筆記具非表示時は影も描かない。拡大率・透明度に追従し、同じ時刻は同じ影になる。
